# 💰 Savings Goal Tracker 
# still in work

A modern financial goal tracking website built with HTML, CSS, and Vanilla JavaScript.

Users can:

* Set a current amount
* Set a future goal amount
* Track progress
* Update savings anytime
* Calculate how long it will take to reach the goal
* View progress graphs and analytics

---

# 🚀 Features

## 📊 Dashboard

Displays:

* Current Amount
* Goal Amount
* Remaining Amount
* Progress Percentage
* Estimated Completion Date

Example:

```txt
Current: R2 500
Goal: R10 000
Remaining: R7 500
Progress: 25%
Estimated Date: 15 Oct 2026
```

# ⏳ Goal Time Calculation

The system calculates:

```txt
Remaining Amount ÷ Monthly Savings
```

Example:

```txt
Goal = R10 000
Current = R2 000
Monthly Savings = R1 000

Remaining = R8 000
8000 ÷ 1000 = 8 months
```

The website then predicts the estimated completion date.
